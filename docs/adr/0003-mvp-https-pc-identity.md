# MVP以电脑钉钉确认身份，统一HTTPS而不再预分配个人SSH账号

用户最终确认用最小闭环重做接入：本组织有效成员首次官方PC钉钉认证自动登记，所有项目共享可见；固定指定管理员仅创建项目／分配职责，成员不管理系统账号、公钥或逐项目名单。以统一HTTPS承载身份、会话与既有附件，替换原先先有成员SSH账号才能扫码的循环前置；代价是双端需要配套新协议和一次性网络／钉钉应用配置，不兼容旧认证回退。

成员管理、动态管理员、机器人通信均不进入MVP。保留真实身份、职责本人决定、私人／项目会话隔离和不自动重发；复用宿主DSH和既有业务状态机。用户选择全新重建、不备份，仅在新PC链路真实验收和成功CI后按准确清单退役旧协作，不删除无关宿主数据；方案和范围见[已确认MVP](<../MVP-账号与电脑钉钉登录方案.md>)。
