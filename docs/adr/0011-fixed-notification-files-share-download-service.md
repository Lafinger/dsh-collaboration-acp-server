# 固定通知文件清单复用已有下载服务

用户确认方案／任务默认显示来源分析范围中的固定版本“参考资料”，成果通知优先显示本版本成果原件；分析范围不等于逐任务依据或成功阅读的证明。为复用已部署双内网下载能力而不把资料ID伪装成成果ID，沿用同一listener及下载路由，新增独立固定资源清单令牌，保持旧成果令牌可用；不扫描项目全部文件、不追随最新版，不把新增展示字段并入审批binding引发历史重发。

这扩展了[ADR-0010](<0010-result-files-via-lan-bearer-links.md>)原先“仅成果附件”的范围，但保留30天持链可下载/可转发、不新增公网或登录流程的取舍。资料与成果按资源类型及固定版本分开绑定，原件不可用明确暴露缺口，不造可用链接；点击下载不产生职责决定。用户授权见[设计记录](<../设计讨论-钉钉文件引用与简洁消息.md>)。
