# 自然语言授权按子句取并集，写工具常驻可见，拒绝时给出可照抄的一句话

状态：已接受并实现于 0.7.2-rc.1。协议未变（`collaboration 3` / `humanAuthorization 2`）。

旧实现把"授权"当成暗号匹配：整条消息命中一个"假设／延后"词就整句作废，出现两个明确指令就一个都不授权，未授权的写工具直接从模型可见工具表里消失。结果是模型连"要提交成果"这件事都无法表达 —— 它看不到工具，也说不出该请人补哪句话，只能回一句"未授权"。

现在把判定拆到子句：按标点与"并且／然后／并"切分，逐句判断。带自己提交动词的假设句、延后句、否定句和信息查询句各自不贡献授权，但不牵连其他子句；其余子句的授权取**并集**。"提交需求分析，然后提交成果"因此同时得到两项授权，而不是零项。

业务写工具（提交需求分析、登记计划、修订计划、提交成果、记录进展、更新项目背景或目标、把通知标为已读、发起验收）改为**常驻可见**：模型始终知道有这些操作，可以规划、可以问人。附件工具不在此列 —— 它们吃的是模型拿不到的不透明句柄，常驻可见只会诱使模型编造句柄。

真正被拒绝的是**调用**，不是可见性：守卫按当前人类消息逐次判定，拒绝文本同时给出操作名称与可照抄的原话，例如 `当前人类消息未授权「提交成果」，所以没有执行；草稿不能登记业务，模型不能代本人确认。要现在做的话，请单独发一句：提交成果。`

`plan_confirm`、`result_review`、`result_accept` 三类本人确认仍对模型完全不可见、不可调用，本期不动。代价是模型偶尔会尝试一个不该它做的写操作并收到拒绝文本；收益是它不再因为看不见工具而无法推进任何事，且人补授权只需照抄一行。
