# 网页扫码替代PC免登，保留同一协作成员与业务归属

状态：**已接受：用户最终确认按最小改版方案实施**。用户分别确认Q1～Q4、Q5～Q8全部按建议；选择默认浏览器中的钉钉官方扫码授权和原DSH自动领取，替代电脑钉钉工作台链路，以减少电脑客户端／工作台／核对码前置。统一HTTPS、自动成员开通、固定管理员、全员项目共享、7天安全设备资格以及职责本人／私人会话／不重发规则不变，不回滚整套旧SSH方案，也不新增公网入口。

切换只撤销既有PC设备登录与旧待完成请求，关闭PC入口，保留成员、业务和会话归属；同一人扫码继续对应原成员。不得通过清库、换serviceId、轮换会话共同epoch或改变成员revision实现“强制重登”，否则会破坏承诺保留的会话。代价是每设备切换时扫码一次、双端配套升级与真实手机普通网络验证；若网络目标不成立，停下重议，不静默公网化。完整边界见[最小改版方案](<../MVP-网页扫码登录改版方案.md>)和[两轮答复](<../设计讨论-网页扫码登录回归.md>)；本记录仅替代[原PC接入ADR](<0003-mvp-https-pc-identity.md>)中的认证入口选择，不推翻其余MVP约束，不代表已经实现或获准立即撤销登录。
