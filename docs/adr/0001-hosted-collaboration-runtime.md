# 协作服务复用宿主 DSH，而非内嵌第二套运行时

用户确认服务器 DSH 安装插件后即承担协作服务，因此从0.2.0起取消独立生产启动方式，使用宿主0.2.0-rc.2的Agent factory、模型路线、工具执行和会话持久化。接入账号与业务事实仍由协作层管理；每个认证成员会话使用自己的Agent scope，只注册工作台工具，插件卸载仅处置自身连接/Agent/SQLite。

这换取统一模型与生命周期管理，但不再支持旧0.1.5独立运行接口，模型会话必须和宿主存储一起备份，宿主管理员属于可信管理者。保留独立CLI作为正式入口或在插件中另建Context都被排除，避免两套运行时和错误的关闭所有权。只对测试使用独立宿主工厂；不自动迁移旧数据、不扩充公网接入/项目权限、不将逻辑会话隔离宣称为OS多租户隔离。
