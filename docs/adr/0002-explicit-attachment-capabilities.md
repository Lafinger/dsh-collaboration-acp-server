# 附件授权与资料归档分离

成员本地文件不是服务器workspace文件；继续把任意绝对路径交给远端模型会扩大成员磁盘权限。采用当前人类消息授权的opaque附件句柄、会话/账号/请求绑定的受限分块读取与双方严格能力协商，拒绝开放SFTP、shell或泛化反向filesystem。

接收回执与正式资料版本分开：传输保持原件hash，解析内容绑定固定资料版本与来源hash，归档按已授权项目及用途/职责类别落盘；同一回执重复归档不新增版本。代价是有独立接收状态和解析记录，但能恢复查询而不重放模型prompt或重复业务写入。资料角色是历史归档类别，不授予人员身份，不替代计划确认。图片能传输/校验不代表已有视觉理解能力；未验证视觉路线明确保留缺口。
