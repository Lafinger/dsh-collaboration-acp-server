# 组织资格同步不等于通讯录导入或删除成员历史

在 ADR0003 的首次官方登录自动开通基础上，对已开通成员主动轮询组织资格与姓名，而非导入整个通讯录或按姓名清理账号；官方明确撤销后保留稳定身份和业务历史，撤销旧设备并冻结原职责，重新登录也不自动恢复职责。与保留永久登录快照、事件订阅或永久禁用 enabled 相比，此选择控制数据范围和外部权限需求，代价是有界轮询延迟、组织核验独立状态以及重新入职后的明确角色确认；暂时核验失败不等于离职，文件 bearer 分享规则仍按 ADR0010/0011，不承诺撤权能追回已分享文件。详见[确认的设计](<../设计讨论-钉钉组织成员同步与撤权.md>)。
