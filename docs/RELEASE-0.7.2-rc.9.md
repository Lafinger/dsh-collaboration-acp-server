# 0.7.2-rc.9：通用文本读取与旧解析缓存刷新

## 范围与来源

## 变更

- 普通文本按内容而非MD/TXT后缀识别，HTML、CSS、JavaScript、JSON、XML、日志、无后缀文本按原文返回。严格UTF-8（含BOM）及带BOM UTF-16 LE/BE，不猜GBK；拒NUL、非文本控制字符，允许TAB/LF/CR/换页。
- 附件、资料、分析和DOCX提取正文取消原256KiB限额，不裁剪、不分页、不自动摘要；原件上传单文件/每消息总计20MiB、最多5个及既有DOCX解压/图片格式安全校验不变。
- 解析器升为1.2.0，附件与归档资料实际读取时刷新旧版或缺失提取缓存；核实原件长度/哈希、派生文本哈希，不要求重新上传、不新增资料版本、不重写历史分析与正式决定。不批量迁移数据库。
- 资料和分析复用统一读取通路；旧的`too_large`分析原因仍保留为历史，不修改历史事实。
- HTML不执行/渲染、不去标签、不加载外链。不可读二进制可另读用户指定说明；不新增关联表，不按文件名猜关联，正式分析中原件/说明须显式列入scope，原件未读缺口仍保留。
- 修正附件归档工具描述：重复内容与最新版本相同会去重，不承诺必新增版本。
