# 钉钉接入实施边界与进度

## 已确认实施范围

依据[架构方案](<DSH-IM-DINGTALK-PLAN.md>)及[审查记录](<DSH-IM-DINGTALK-REVIEW.md>)开始实现。三个仓库：协作服务端、协作客户端，以及用户指定的[独立dsh-im fork](https://github.com/Lafinger/dsh-im)，基线为上游v4.39.0提交`f6a9dd0abbeae605e459a660a9922c9a703e6aa0`。fork本地分支`feature/collaboration-dingtalk`，本次不推送或发布远端。

- 不增加上下文共享／交接、钉钉正式业务写入或其他IM渠道。
- 实现身份认证、项目访问控制、私聊／群／项目隔离、受控通信与可靠消息状态。
- 客户端提供登录状态及项目选择；未绑定项目的旧会话仅保留原成员认证后的只读历史，不自动迁入新业务上下文。
- 管理员通过服务器本地命令维护成员绑定、管理员资格、项目参与名单、角色、目标与订阅；不是公网管理面板或模型管理工具。
- 钉钉支持固定格式的窄化只读查询和受限主动自然语言问答，使用现有服务器模型路线；本次测试使用模拟模型，不调用真实付费模型。
- 设备登录最长12小时；组织资格复核缓存最多5分钟，过期且复核失败拒绝访问。受保护群发送前重核受众；通信正文默认保留90天，管理员明确命令清理，不联动删除正式业务事实和旧批次失效边界。
- 真实组织、内部应用与HTTPS尚未准备；提供私有配置模板和准备清单，平台未验收项不能标记通过，不要求用户把秘密发在聊天中。
- 先完成代码、自动化测试、构建和隔离集成验证；不升级现用容器、不清空现有数据、不发布、不改变现用GUI插件配置。后续真实平台接入／部署另行确认。

## 当前实现（本地未发布）

- 服务端实际Cordis入口已装配新版OAuth、设备登录、scoped unionId→内部userId、组织详情复核、项目ACL、角色／管理员分离、schema10方案暂停、限定登录HTTP和本地管理CLI。SSH仅为传输身份，旧v2拒绝；设备token哈希保存，客户端Host内存保存。官方明确资格失效与网络临时故障分开处理：失效推进成员revision、撤销设备并暂停待生效方案，网络故障则到期拒绝、不猜离职事实。
- 客户端实际Host适配器及浏览器bundle已实现登录／领取／登出、服务器状态复核、不可变项目选择、只读历史和通信查询；同源本机RPC不返回token或proof。断线登出尝试撤销原token，不承诺网络失败时服务器已经撤销。
- 独立fork专属 `@xmanrui/dsh-im/controlled-dingtalk` 子入口只注入同Host通信契约，不加载默认Harness问答、管理HTTP、卡片审批、文件或会话同步。真实Cordis组件生命周期与三仓库装配已在离线宿主测试中核对。
- 通信inbox持久后ACK、去重／epoch、显式请求／关联答复／收悉、目标和成员revision、逐段outbox及unknown／partial不盲重放已实现。答复路由在原请求固定，不换目标；群成员完整名单不成立时停止受保护发送。本人提醒同时检查当前角色、版本、订阅与关联对象归属。只有完成且已提交的最后模型消息进入IM出站，中间文本、思考、失败／取消片段不投递。
- 附件在异步接收／归档提交前再次事务内授权，撤销时SQLite和服务拥有的文件回滚；旧重置脚本同时检查配置与库内安全标记，不能按旧配置抹掉新权限／去重边界。

## 已验证与剩余事项

最终完整检查已通过：服务端285业务、70安全／接入、18宿主集成；客户端36单元、8集成；三仓库联合6项（含真实React页面），客户端协议联合1项；fork全套4146项，4139通过、7项上游既有平台条件跳过、0失败。新增附件提交竞态、组织明确撤销、空缺角色逐角色确认、断线登出、真实React页面、异步停用、目标变化及发送前资格撤销回归均包含在结果中。部署检查11项中9通过、2项POSIX条件在Windows跳过，不冒充Linux新版通过。服务端／客户端tar包脱离源码目录加载通过，fork专属包的真实Cordis隔离加载与依赖闭包通过。具体最终证据将记录在[离线验收记录](<DINGTALK-VERIFY.md>)。

**日志保留范围已由用户明确选择覆盖钉钉模型日志，并已实现。** 新OS本地停服维护命令使用服务锁与JSONL会话内核锁、登记目录／header复核、dry-run清单hash、预提交purge tombstone、逐文件精确删除；兼容明文／zstd与中断恢复，不递归清宿主所有会话。90天上下文换新ID，过期／清理旧ID不复活。维护单元6项及真实宿主集成3项均通过并包含于上述计数。操作见[日志保留维护](<DINGTALK-RETENTION.md>)；只删除临时测试数据，实际数据没有清理。

**真实平台尚未验收：** 组织、内部应用、HTTPS与官方权限／私聊可信字段、真实群类型及成员API、真实发送回执、断线和崩溃边界均需后续部署管理员准备。离线模拟只证明代码和宿主契约，不代表平台提供这些能力；条件不足时不启用双向链路。当前GUI未安装变更，现用容器／模型路线／数据未改，没有付费调用、推送或发布。

操作及停止条件见[部署指南](<DINGTALK-DEPLOYMENT.md>)，原架构／审查文档保留历史时点。
