# 0.7.2-rc.11：钉钉组织资格与姓名主动同步

## 已确认范围

启动及每5分钟复核本服务已开通成员，不导入全组织；显式角色候选刷新执行权威核验并合并/短时防抖，角色提交强制核验目标。同步姓名不改变稳定账号、角色版本或会话归属；同名不同身份不合并。

- 独立组织资格状态与最近核验时间，分清未知/已确认撤销/需重新登录和本地停用；暂时网络或权限故障不当离职，过期资格暂停业务，未知不可新分配。
- 端点精确处理 union 查询60121、详情33012（数字/字符串），active表示钉钉激活而非在职。
- 确认失效后撤销设备、终止对应连接/在途轮次并阻止后续职责操作和新增通知，保留历史。原职责明确标记待重新分配；重新入职同身份本人重新登录后仍需管理员确认职责，旧短号/旧设备/暂停方案不自动恢复。
- 新增组织状态及职责冻结表、待扫码请求修订守卫，旧业务事实与私人归属保留。不按姓名删库，不重发或重放决定。
- 复用原下载服务，已发bearer链接不按成员单独撤销，已下载文件不可追回。

协作4／附件2／人类授权3不变，配套客户端0.6.3-rc.9展示核验状态、原角色可读姓名、同步失败及本人最新姓名；旧客户端仍由服务端强制保护，但不具备完整新展示。
