# 项目背景／目标编辑（v0.4.2）

状态：v0.4.2已正式发布并完成Docker保留升级；[发行与保留验收](<PROJECT-DETAILS-RELEASE-VERIFY.md>)记录完整证据。用户真实模型字段更新待明确授权后执行，升级没有自动写草稿。

`project_update_details`只编辑已存在项目的background／goal，不创建替代项目、改key/name、角色成员、资料、分析、方案或任务。未知字段继续pending，不从分析草稿或历史日期自动补全。project_get返回实际project及pending_fields。

## 明确编辑语义

- project_id必填，background／goal至少提供一个；只允许这三个工具字段。
- 未提供字段（undefined）保持当前存储值；非空字符串去首尾空白、每项最多2000字符。
- null、空串／纯空白、非字符串、额外字段拒绝。首版不新增清空已有值的能力。
- 两字段在同一写事务校验和更新，不因一个字段失败而部分写入；读旧值和归档检查位于同一写锁内。
- 项目ID／key／name／created_at与所有关联记录保持；重复同内容更新不创建副本／资料版本。
- 已归档项目拒绝更新；附件turn guard继续拒绝项目详情写入，授权上传不等于授权改目标。
- 无新增角色权限／项目ACL。认证成员使用既有业务规则；显式用户授权由当前请求给出，不把schema描述误称机械语义授权判定。
- 这是可变项目说明，不是不可变资料、分析建议或方案确认；当前原业务没有项目详情修订表。本工具不声称提供结构化修改历史。
