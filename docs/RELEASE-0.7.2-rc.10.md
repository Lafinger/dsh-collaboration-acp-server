# 0.7.2-rc.10：钉钉固定文件引用与简洁消息

## 内容

- 方案确认、任务提醒、本人职责成果评审、下游输入接收统一中文职责、分段重点与精确命令；处理回执缩短并保留成功、重复、失效、冲突或未执行的区别。
- 默认沿来源分析的固定资料范围显示“参考资料”，不是逐任务依据或全文已读证明。任务沿产生其当前版本的固定方案追溯；成果沿自身任务版本追溯，而非取下游无关来源。不猜名称、不扫描全项目、不使用最新资料替换历史版本。
- 复用原有双内网下载listener、页面及流式原件响应；新固定清单包含本次成果原件（优先）和去重参考资料。新增notification_download_tokens清单令牌表；旧result_download_tokens及既有成果链接保持兼容。
- 固定版本、30天有效、持链可下载/可转发，仍不新增公网或成员登录。下载不代表同意、完成或接收。新清单页区分参考资料与成果原件；文件缺失或不完整明确提示，不造链接。
- 下载原件采用只读原件路径/类型/大小/哈希核验，不调用资料解析、不刷新缓存或新增资料版本。
- 保留普通文本预算、安全过滤、必要风险与完整操作命令；不堆内部长ID、路径/hash、空值和长任务原文。完整业务内容仍须在DSH核对。

## 不变与升级

协作4／附件2／人类授权3和客户端行为不变；客户端0.6.3-rc.8继续兼容，本轮不要求客户端更新，不另发无变化的客户端版本。没有模型调用、自动代批、新审批类型或权限扩张。新模板不改变固定binding/去重，不重写已排队消息，不自动补发历史通知、不重放审批决定。

服务端须从固定标签的成功CI产物升级，保留原业务库、身份、会话、原件、下载token和配置。首次初始化只新增下载清单表/索引，不改业务历史。维护停止后备份双库与私有文件，代码回滚不恢复数据库或配置。
